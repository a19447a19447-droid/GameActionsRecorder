# GameActionsRecorder

This is a vibe coded project.
It runs with python.

Introduction:
Inspired by selenium ide and scratch, the game action recorder is a system designed to do simple and repetitive jobs. 
I worked out in this project because i m playing a heavily grinded game. This system basically just record what you did and repeat what you are doing.

How to use:
1. you have to manually playing it once, with the action recording on. 
2. the next time you can just execute what you recorded.
3. you may edit, delete, append your actions flow if you feel you need to.
4. you can create a action flow yourself without recording.

External codes:
1. the system DO support external codes but have very limited support to external code.
2. it was suggested to use "example.py" as external code template.

Extra:
1. it have if else statement and while for loops, but the usage is very limited.
2. feel free to submit a issue if you found any bugs.
